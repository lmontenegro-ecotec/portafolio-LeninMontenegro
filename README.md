# Portafolio Personal — Lenin Montenegro

Sitio web personal desarrollado con **HTML** y **CSS** como parte de la actividad integradora 1 de la materia
Programación Web. El portafolio presenta información sobre mi de manera básica, habilidades,
proyectos y una sección de contacto.

## Autor
Lenin Montenegro — Ingeniería en Sistemas Inteligentes
GitHub: [lmontenegro-ecotec](https://github.com/lmontenegro-ecotec)

## Descripción

El sitio está compuesto por una sola página (`index.html`) dividida en secciones
enlazadas desde el menú de navegación:

1. **Encabezado** — nombre, carrera y menú de navegación.
2. **Inicio** — título principal, descripción breve e imagen personal.
3. **Sobre mí** — quién soy, mis intereses y mis objetivos profesionales.
4. **Habilidades** — habilidades técnicas y personales.
5. **Proyectos** — proyectos con nombre, descripción, imagen y enlace.
6. **Contacto** — formulario visual con nombre, correo, mensaje y botón de enviar.
7. **Pie de página** — nombre, año y enlace al perfil de GitHub.


## Tecnologías utilizadas

- HTML5 con etiquetas semánticas (`header`, `nav`, `main`, `section`, `article`, `footer`).
- CSS3 externo con variables definidas en `:root`.
- Git y GitHub para el control de versiones.

## Cómo verlo

1. Descargar o clonar el repositorio.
2. Abrir el archivo `index.html` en cualquier navegador web.
